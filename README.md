## 👩🏻‍💻 a little about me

Hi, I'm **Rabia**, a Computer Systems Engineering graduate who found myself increasingly fascinated by one question:

> **How can we build systems that can actually learn, understand, and help?**

# 🩺 Featured Project — DermAI

**Deep Learning-Based Improvement of Skin Disease Identification Using Comparative Pre-Trained CNN Models**

A heterogeneous quad-ensemble medical image classification system (Final Year Project) built on the **HAM10000** dataset.

### 🧠 Models

`MobileNetV3` · `ResNet50` · `EfficientNetB0` · `EfficientNetB3`

### 🔎 Techniques & Stack

* Transfer Learning, Weighted Loss, Grad-CAM Explainability
* FastAPI backend · React frontend · Supabase · Groq API chatbot

The goal wasn't simply to chase a high accuracy number, but to understand **where models succeed, where they struggle, and why**.
